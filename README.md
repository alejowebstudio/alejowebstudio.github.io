# Alejo Web Studio

**Webs rápidas y seguras para pequeños negocios de Latinoamérica**: informativas o con funciones dinámicas (catálogo editable, formularios, reservas y citas). Clínicas, veterinarias, talleres, restaurantes y comercios.

## Cómo trabajamos

1. **Maqueta gratis en 48 horas.** Si no te convence, no pagas nada.
2. **Resumen por escrito** con lo que incluye, el precio y el plazo.
3. **50 % para empezar, 50 % al terminar**, antes de publicar.
4. **La web es tuya.** El dominio queda a tu nombre y te entregamos todos los archivos.

## Qué hay en este repositorio

| Carpeta | Contenido |
|---|---|
| `index.html` | Página principal |
| `assets/site.css` | Estilos compartidos (modo claro y oscuro) |
| `demos/` | Seis webs de ejemplo de negocios ficticios, cada una con un estilo: [clínica dental con reservas](https://alejowebstudio.github.io/demos/dental/), [tienda online con carrito](https://alejowebstudio.github.io/demos/tienda/), [estudio jurídico](https://alejowebstudio.github.io/demos/abogados/), [veterinaria](https://alejowebstudio.github.io/demos/veterinaria/), [taller](https://alejowebstudio.github.io/demos/taller/) y [restaurante](https://alejowebstudio.github.io/demos/restaurante/) |
| `herramientas/` | [Herramientas gratis](https://alejowebstudio.github.io/herramientas/): enlace y QR de WhatsApp, vista previa en Google y test de tu web |
| `automatizaciones/` | Servicios de automatización y el [kit de recordatorios de citas](https://alejowebstudio.github.io/automatizaciones/recordatorios-citas/) (Google Sheets + Apps Script), con código abierto |
| `condiciones/` | Pagos, plazos, cambios, devoluciones y privacidad |

## Técnica

- HTML y CSS estáticos, sin base de datos ni servidor: no hay nada que hackear. El JavaScript (calculadora, comparador, herramientas y demos) se sirve desde el propio sitio, sin librerías externas.
- Política de seguridad de contenido (CSP) que solo permite scripts propios.
- Sin cookies ni rastreadores.
- Publicada con GitHub Pages y HTTPS.
