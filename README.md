# Alejo Web Studio

**Webs rápidas y seguras para pequeños negocios de Latinoamérica.** Clínicas, veterinarias, talleres, restaurantes y comercios.

🌐 **[alejowebstudio.github.io](https://alejowebstudio.github.io)** · ✉️ alejo.webstudio@gmail.com · 📷 [Instagram](https://www.instagram.com/alejowebstudio/)

---

## Cómo trabajamos

1. **Maqueta gratis en 48 horas.** Si no te convence, no pagas nada.
2. **Resumen por escrito** con lo que incluye, el precio y el plazo.
3. **50 % para empezar, 50 % al terminar**, antes de publicar.
4. **La web es tuya.** El dominio queda a tu nombre y te entregamos todos los archivos.

## Precios (USD, pago único, iguales para todos los países)

## Qué hay en este repositorio

| Carpeta | Contenido |
|---|---|
| `index.html` | Página principal |
| `assets/site.css` | Estilos compartidos (modo claro y oscuro) |
| `demos/` | Tres webs de ejemplo de negocios ficticios: [veterinaria](https://alejowebstudio.github.io/demos/veterinaria/), [taller](https://alejowebstudio.github.io/demos/taller/) y [restaurante](https://alejowebstudio.github.io/demos/restaurante/) |
| `automatizaciones/` | Servicios de automatización y el [kit de recordatorios de citas](https://alejowebstudio.github.io/automatizaciones/recordatorios-citas/) (Google Sheets + Apps Script), con código abierto |
| `condiciones/` | Pagos, plazos, cambios, devoluciones y privacidad |

## Técnica

- HTML y CSS estáticos, sin JavaScript ni base de datos: no hay nada que hackear.
- Política de seguridad de contenido (CSP) que bloquea scripts externos.
- Sin cookies ni rastreadores.
- Publicada con GitHub Pages y HTTPS.
